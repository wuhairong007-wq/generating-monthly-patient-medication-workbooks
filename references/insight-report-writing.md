# 洞察报告写作规则

报告必须遵循 `insight-report-template-contract.md` 与其对应的 `assets/patient-insight-report-generation-prompt-template.md.docx`。报告包含服务数据陈述、统计图表、图表类型和核心信息说明，并围绕产品、服务周期、合同目标和区域特征组织叙事。事实、解释、局限性和建议分段表达；没有合同阈值时使用默认服务评估口径并明确说明。禁止把相关性写成因果性，禁止引用模板示例数字或未由源文件支持的临床结论。

正文叙述密度应与用户提供的参考模板相当。执行摘要和每个核心二级分析小节原则上至少包含三个完整分析层次：先陈述数据规模、分布或覆盖情况，再解释集中度、差异、缺口或统计边界，最后提出能够由当前数据支持的服务动作。不得只用一段数字罗列和一句泛化建议结束小节。智能随访的每个三级维度至少包含回答分布、结构解读和分层复核建议。建议必须具体说明关注对象、核查字段或下一步动作，不能使用空泛的“持续关注”“加强管理”代替分析。

标题编号固定为一级“一、”、二级“（一）”、三级“1、”，正文固定 28 磅行距。图表和表格居中，表头使用蓝色底纹；图注和表注单独置于对象下方，分别使用章内连续的“图X-X：”和“表X-X：”。

不良反应清单选填时，省略文件不代表已确认零事件。保留安全监测与风险评估章节，描述可执行的事件登记、患者级复核及统计边界，避免推算事件率或风险分布；提供空清单时可描述周期内零条登记记录，但不能作无风险结论。

月度4/5表模式只描述登记事实：主表同月提醒汇总、方案确认记录、明确联合用药药名、实际随访十题及自评六题。A/B回答不能一律称正向，方案登记不能写成实际服药，未匹配事件不能写成无风险。源月份与服务周期不同或不是完整自然月时，月度提醒总数标记为无法统计，逐条日期记录照常筛选；缺少健康管理方案、响应日志、监测日志或药品规格时不输出对应统计。二三级标题按月度模板适配条款执行，保留九章及完整解释层次。
